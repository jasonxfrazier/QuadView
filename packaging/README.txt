QUADVIEW FOR WINDOWS 10/11 (x64)

1. Install LibreWolf from https://librewolf.net/ if you do not have it already.
2. Run QuadViewSetup-0.1.0.exe and open the QuadView desktop shortcut.
3. Accept the first-run fullscreen setup if you want video fullscreen confined
   to each window. Close LibreWolf before launching a QuadView session.
4. Fetch links, choose up to four games, then click Launch.
5. Click each video's fullscreen button yourself.

No Python, uv, terminal commands, or extra browser downloads are needed.
The link-fetching browser is included. LibreWolf is installed separately.
